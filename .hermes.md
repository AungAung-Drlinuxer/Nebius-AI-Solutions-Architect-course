# Project Context

This repository is a technical course (Nebius Certified AI Solutions
Architect exam prep) written in Burmese for engineers.

Before writing or editing any chapter, follow `WRITING_RULES.md` in this
repository. Key points:

- Natural Burmese; keep established technical terms in English
  (IAM, Kubernetes, Slurm, InfiniBand, Terraform, observability...).
- Chapter progression: problem → core concept → technique comparison →
  practical configuration → operational cautions → self-check.
- Mermaid figures with caption + figure walkthrough for workflows.
- Commands: explain what each does; flag version-dependent behavior.
  Never invent specs, commands, prices, or benchmark numbers.
- Every chapter ends with a short "Technical review notes" section.
