**Role description (Exam Guide မှ):** ML workload requirements နှင့် underlying infrastructure
ကို ချိတ်ဆက်ပြီး Nebius AI Cloud ပေါ်တွင် end-to-end AI infrastructure solutions များ
design လုပ်နိုင်သူ။ workload, team, budget, timeline ကို အကဲဖြတ်ပြီး architecture နှင့်

ရွေးချယ်ခြင်း။ architectural decisions များအတွက် တာဝန်ယူပြီး stakeholders များအား
strategic advisor အဖြစ် ဆောင်ရွက်ခြင်း။ (CloudOps နှင့် ဆန့်ကျင်ဘက် — architect က
architecture decisions ချသည်)

## Exam Domains ၄ ခု (~25% စီ)

| Domain | ဘာသာရပ် |
|---|---|
| 1. Design high-performing architectures | GPU/platform building blocks, storage architecture, training-platform support stack, deployment shape, orchestration overlays, distributed-training architecture tradeoffs |
| 2. Design resilient architectures | Checkpoint/restart strategies, observability (logs/metrics/traces), validation/benchmark/acceptance plan, failure handling & support model, migration & handover |
| 3. Design efficient & cost-aware architectures | Capacity/quotas/onboarding cost, reuse & automation, FinOps (governance/monitoring/decommissioning), cost tradeoffs, right-sizing, multi-cloud connectivity & data ingestion |
| 4. Design secure architectures | Identity & access model, private connectivity, secrets/audit/compliance, shared responsibility & tenant isolation & least privilege, data classification, encryption, incident response |

## Course structure

- `00_orientation_exam_guide` — စာမေးပွဲ မိတ်ဆက်၊ role/domain map၊ study roadmap
