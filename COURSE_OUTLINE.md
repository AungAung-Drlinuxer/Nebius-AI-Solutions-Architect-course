# COURSE OUTLINE — Nebius AI Solutions Architect

Nebius Certified AI Solutions Architect exam prep — 4 domains (~25% each), 6 modules.

## PART I — Orientation

### Module 00 — Orientation & Exam Guide
📁 `00_orientation_exam_guide/` — explanation · exercise · solution
- Role description (architect vs CloudOps operator), target candidates (3+ yrs cloud)
- Exam format (MCQ, 1 hour, remote proctoring), waitlist registration
- Domain map + design-first study method + roadmap
- Relationship to NCO-201 (CloudOps) and AI Infrastructure Engineer certs

## PART II — Exam Domains

### Module 01 — Design High-Performing Architectures (~25%)
📁 `01_design_high_performance/` — explanation · exercise · solution
- Selecting GPU architecture and platform building blocks for a workload
- Designing storage architecture for AI workloads
- Designing the training-platform support stack and user environment
- Defining workload outcomes and deployment shape
- Orchestrator and workload-framework overlays
- Distributed-training architecture and its tradeoffs

### Module 02 — Design Resilient Architectures (~25%)
📁 `02_design_resilient/` — explanation · exercise · solution
- Checkpoint and restart strategies
- Observability scope: logs, metrics, traces
- Validation, benchmark, and acceptance plan
- Failure handling and operational support model
- Migration and handover path

### Module 03 — Design Efficient & Cost-Aware Architectures (~25%)
📁 `03_design_cost_aware/` — explanation · exercise · solution
- Capacity, quotas, and onboarding cost planning
- Reuse and automation to reduce operational effort
- FinOps: governance, cost monitoring, decommissioning
- Tradeoffs where cost outweighs raw performance
- Cost dimensions in performance and right-sizing
- Multi-cloud connectivity and data-ingestion pipelines

### Module 04 — Design Secure Architectures (~25%)
📁 `04_design_secure/` — explanation · exercise · solution
- Identity and access model design
- Private connectivity for control-plane and operator access
- Secrets, audit, and compliance posture
- Shared responsibility, tenant isolation, least privilege
- Data classification, encryption, incident-response posture
